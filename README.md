# Welpak Atlas — Umbrel community app store

Separate copies of Hermes Agent, Murmur, and OpenCode for Atlas (Brad Welsh's PA), so they run alongside the official apps on the same Umbrel without sharing data.

| App | ID | Port | Upstream version |
|---|---|---|---|
| Atlas Hermes | welpak-atlas-hermes | 18890 | 0.22.5-patch.2 |
| Atlas Murmur | welpak-atlas-murmur | 18893 | 0.11.1 (finds Atlas Hermes, not the official Hermes Agent app) |
| Atlas OpenCode | welpak-atlas-opencode | 4196 | 1.19.5 |

These are manifests only. No keys or secrets are stored here. Add this repo in Umbrel under Settings → App Store → Community App Stores.
